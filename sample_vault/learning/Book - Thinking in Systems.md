# Notes

A system is a set of elements interconnected to achieve a purpose. The key building blocks are **stocks** (things that accumulate) and **flows** (rates that change stocks).

## Feedback loops
- *Balancing loops* push a stock toward a goal: a thermostat, hunger, inventory restocking.
- *Reinforcing loops* amplify change: compound interest, population growth, viral adoption. Left unchecked they grow exponentially until a limit — food, space, money — kicks in and a balancing loop takes over.

## Delays
Delays in feedback cause oscillation. If you react to stale information you overshoot, then overcorrect.

## Leverage points
The least obvious leverage points are the most powerful: changing the goals of the system or the paradigm it runs on matters more than tweaking parameters.
