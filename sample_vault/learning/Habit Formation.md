# Habit Formation

Habits run on a loop: **cue → craving → response → reward**. Make the cue obvious, the response easy, and the reward immediate.

- Habit stacking: attach a new habit to an existing one ("after I pour coffee, I review flashcards").
- Two-minute rule: scale any habit down to two minutes to get started.
- Never miss twice. One missed day is noise; two is the start of a new habit.

Small daily improvements compound — a reinforcing loop. Identity follows behaviour: every repetition is a vote for the person you want to become.
